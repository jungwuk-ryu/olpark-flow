# 실용성 검증 후속 자료 — 팀원 A·C

팀원 B의 시간순 원자료 기준선은 [검증 문서](../methods/validation.md)에 있다. 모델 → 계산 전체 채점은 실행 자료가 없어 미완료다.

- 팀원 A: `ml/data/README.md`에 적힌 가공 자료가 있는 로컬 폴더를 알려주거나 권한 있는 팀 경로로 전달한다. `prepared/response/sessions.parquet`, `rail_hourly.parquet`, `calendar.csv`와 운영 추정기가 쓰는 수단·목적지 자료가 필요하다. 키는 전달하지 않는다.
- 팀원 A: 과거 공지·발권·관객층·수단 분담의 정보 가용 시점을 기록한다. 2025년 월별 재학습에는 원점 이전 자료만 쓰고 2026년 배포 번들을 재사용하지 않는다.
- 팀원 B: 같은 원점의 예측을 팀원 C의 계산 입력으로 변환해 같은 지점·단위·정시 구간에서 채점한다. 9호선 두 역 자료가 확보되기 전에는 A/B/C 전체 비중의 정확도를 발표하지 않는다.

## 재현을 위해 제안하는 저장 필드

다음은 데이터 구조 제안이다. 공연별 결과 저장·요원 배치 저장·설정·로그인 화면은 구현하지 않았다.

| 묶음 | 필요한 값 |
|---|---|
| 예측 원본 | 실행 ID, 익명 회차 ID, 예측 발행시각, 학습 종료일, 모델 판본·해시, 특성 자료의 가용시각·해시, 예측 인원·수단·방면·시간 곡선과 단위 |
| 계산 조건 | 연결된 예측 실행 ID, 보행망·가정값 해시, 운영자 수정 인원·실제 종료시각, 통제·폭 변경·요원 배치, 계산 범위 |
| 계산 결과 | 방면별 역 입구 도착 시계시각, 문별 출차 시계시각, 남은 인원·차량, 최대 대기·대기 합계, 경고 |
| 채점 근거 | 실측 파일 해시, 지점·시간 집계 규칙, 제외 사유, 동일 표본 기준선, 점수와 관측 단위 |

서로 다른 입력을 같은 결과로 덮어쓰지 않도록 실행 ID로 연결하고, 관측·예측·운영자 입력·가정을 구별한다. 실제 종료시각을 사후 입력한 계산은 전날 예측 성능과 분리해 저장해야 한다.
