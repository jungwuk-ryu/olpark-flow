# 퇴장 수요의 추정과 현장 검증 프로토콜

[설계 개요](README.md) · [교환 계약과 운영](integration-operations.md)

## 1. 연구 단위와 예측 시점

단위는 **공연 회차, 사람의 이동, 교통기관의 집계** 세 가지다. 같은 시간에 세 공연이 끝나도 한 역의 21~22시 승차 정답은 하나다. 독립 사례 수를 보고할 때에는 시간행과 별도로 회차·행사일·투어·공연장 수를 센다.

| 기호 | 정의 |
|---|---|
| `e, o, d, k` | 한 공연 회차, 관객이 나온 공연장 출구, 첫 귀가 수단으로 연결되는 목적지, KST 5분 출발 구간 |
| `j, I` | 역·호선/정류장·방향/차량 게이트의 관측 지점과 자료원이 정의한 시간구간 |
| `Y(j,I), B(j,I)` | 지점의 전체 승차인원 또는 출차대수와, 해당 공연 조건을 제외한 비교 배경수요 |
| `N(e), X(e,o,d,k)` | 같은 정의의 공연별 퇴장 대상 총원과 그중 특정 출구·목적지·시간에 출발하는 사람 수 |
| `as_of` | 이 시각까지 시스템이 알 수 있었던 정보로 예측하는 절단점. 전날 17시, 종료 예정 60분 전, 15분 전, 현장 갱신을 별개 과제로 평가 |

시각은 원문과 UTC 오프셋을 보관하고 행사·달력 결합은 `Asia/Seoul`로 한다. `service_date`와 실제 달력 날짜를 분리한다. 23:55~00:05와 자정 뒤 승차·출차는 날짜 경계를 넘어 연결한다. 구간은 시작 포함·끝 제외다. 예컨대 공연 종료 예정이 21:40이면 철도 원자료 21~22시는 종료 전후가 섞인 1개 정답이다. 관측 출구 5분 자료가 있으면 별도로 21:40~21:45부터 평가한다.

### 시점별 자료 계약

각 사실에 `valid_from/to`(일정·관측이 가리키는 시각), `published_at`, `ingested_at`, `revision_id`, `source_hash`를 둔다. 운영자 확인에는 `confirmed_at`, 현장 기기에는 `observed_at`을 추가한다. 운영 재현에서 선택할 값은 그때 도착했고 공개·확인됐으며 해당 시간에 유효한 버전이다. 동일 키가 정정되면 선행 버전으로 과거 요청을 다시 재생할 수 있어야 한다.

| 입력 | 미래 예측에 허용하는 버전 | 부정확한 시각의 처리 |
|---|---|---|
| 행사·관객 규모 | 절단점 전에 접수된 주최사 값, 당시 저장한 공식 일정, 날짜가 확인된 최초 공지 | 원본 등록일만 있고 수정 이력이 없으면 후향 실험의 가용성 상한으로 표시. 해당 행사 제거 실험도 수행 |
| 날씨 | 해당 격자에서 당시 수신한 발표분 중 대상 시각이 일치하는 마지막 예보. 예보의 선행시간·변수별 결측도 특성으로 보관 | 발행 범위 밖은 계절별 시나리오, 누락은 기상 변수가 없는 백업 모델. 확대 구간 강수·풍속 범주를 연속 실측으로 변환할 때는 코드표와 버전 필요 |
| 교통 이력 | 절단점 당시 공개·수신된 마지막 자료와 그 경과시간 | 2025 연간 철도 파일의 게시일은 2026-06-08 및 10-02다. 같은 해 앞달 정답으로 2025년 모델을 학습한 검증은 후향 적합도 실험으로 기록 |
| 휴일·운영 변경 | 절단점까지 공표된 휴일·열차 운행·도로 통제·출구 운영 계획 | 발표 이전에는 당일과 전후일 파생변수 모두 종전 달력으로 계산. 소급 정정·취소 시험 포함 |
| 실입장·현장 흐름 | 해당 장소와 시각의 연결 권한·가동 상태·지연이 확인된 집계 | 전날 예측과 당일 관측 동화는 다른 실험군. 센서 추가 전후 결과를 같은 데이터 가용 조건에서 짝지어 비교 |

실험 기록에 **학습 종료 시점, 정답 게시일, 피처 절단점, 모델 가중치 공개 시각, 예측 생성 시각, 정답 동결 시각**을 함께 둔다. 2026년에 얻은 가중치와 정제·검수 규칙을 2025년 데이터에 적용한 결과는 2026년 설계의 후향 비교다. 2025년도 당시 가능한 서비스를 재현하려면 그때 이용 가능했던 학습 자료와 모델이 따로 필요하다. [로컬 수집 시점·범위](../../../ml/data/README.md)

## 2. 학습 데이터 생성과 계보

1. **원본 보존.** 파일명·상품 월 대신 실제 시간열을 검사한다. 원본 URI, 발행기관, 추출 범위, 원본 해시, 레코드 수, 처음·마지막 시각, 라이선스, 해석 규칙 버전을 보관한다. 원본을 다시 받으면 새 스냅샷을 만든다.
2. **관측 범위를 별도 표로 관리.** `source × point × interval`별로 확인된 관측, 명시적 0, 일부 수신, 공급처 누락, 운영 중단, 적용 대상 밖을 구분한다. 기관의 전송 완료와 계측값 기재 여부를 각각 기록한다. 미기재 셀에는 정답의 가중치 0을 주고 평가 분모에서 제외한 수와 이유를 공개한다.
3. **변하지 않는 기본 키.** 철도는 자료원·수송일자·역번호·호선·승하차 구분·원 구간, 버스는 자료원·일자·표준 정류장·방향·노선·순번·구간, 주차는 자료원 내부 행 식별자/검증된 원행 지문과 입·출차 사건을 사용한다. 차량이 같은 초·같은 문을 동시에 지날 수 있어 그 두 값만으로 중복 제거하면 실제 대수를 잃는다.
4. **시간·공간 결합.** 표준 정류장 ID와 ARS 코드, 노선번호와 내부 노선 ID를 나눠 저장한다. 위치 스냅샷의 적용일·게시일을 확인한다. 지점별 원 단위로 센 뒤 목적지 계층을 연결한다. 올림픽공원역 5·9호선을 각각 검증하고 지상 출입구로의 배분은 별도다. 역 내부 환승·집계 정의를 확인한 경우에만 같은 물리 통행으로 연결한다.
5. **행사 결합.** 회차 키는 내부 행사 ID·장소·현지 시작·회차 버전에 연결한다. 중복·장소 혼합·기간 표기·요일 규칙·휴일 예외를 먼저 해소한다. 한 지점·시간에 여러 회차 특성을 집합으로 연결해 목적변수는 한 행으로 유지한다. 같은 장소명 별칭·투어 재공연의 원본 대응표는 제한된 연구 저장소에 둔다.
6. **학습표 생성.** 교통 정답 테이블과 시점별 피처 테이블을 분리한다. 키는 수단·지점·측정 구간·예측 시점·버전이다. 같은 시간합계를 노선이나 회차마다 복사하지 않는다. 측정 품질, 출처·단위, 관측 가능 범위, 결측 마스크를 열로 보존한다.

**주차.** 월별 CSV와 문화광장 API는 표본과 처리 규칙이 다르다. 같은 자료원이 겹치는 월의 시각·문별 분포, 두 소스 간 잔차, 날짜별 누락, 입차 후 장기주차를 평가해 출처별 모델/검증표를 만든다. 날짜 문자열의 입차 누락이 출차 인원에도 영향을 준다. 월별 자료에서 입·출차 날짜가 이틀 이상 차이 나는 차량은 17,430대다. 누락 입차일의 당일과 이후 1·3·7일을 각각 제외해 시험 민감도를 비교하고, 남은 꼬리의 보수적 오차 범위를 낸다. 원격 API에서 역전 6,288행을 제외해도 문별 처리량 대표값은 같았지만 개별 날짜의 출차 분포는 변했다. 처리량은 흐를 수 있는 대수의 근사, 실제 출차는 그날 관측된 대수다. 정체가 있을 때 관측된 출차를 잠재 출차 요청량으로 사용하려면 대기·처리 제약을 함께 모형화한다. [시각 역전 분석][vehicle-audit]

**버스.** 완결 페이지에도 양의 운행횟수에 승차 공란인 경우가 285,721행 있다. 기관의 공란 정의와 대조 가능한 일합계가 있어야 학습 규칙을 바꿀 수 있다. 비교 가능한 38일·8,978개 정류장–일의 T-DATA 기재 승차합은 3,291,608명, 서울시 일합계는 3,335,379명이다. 두 양의 총합이 가까워도 개별 시간칸의 결측은 남는다. 일합계 모델은 별도 결과로 낼 수 있다. 월별 시간합계를 한 달의 각 공연일에 복제하면 대상 일자의 피크 오차를 평가할 수 없다. [버스 원자료·집계 설명](../../../ml/data/README.md)

**기상.** 관측소 108과 공연장 격자 두 곳을 구분한다. ASOS 시간 강수 공란의 의미는 원자료 규정으로 판정한다. 17시→20시의 3시간 선행 자료는 확보한 특정 조합이다. 모든 예측 요청의 3시간 선행 예보가 존재한다고 일반화하지 않는다. 비 오는 날 표본에서는 강수 유무와 연속 강수량, 공연장 방문 결정 전의 예보와 종료 전의 예보를 구분한다. [기상청 지점 자료][kma] · [로컬 예보 명세](../../../ml/data/raw/D08/point_archive/coverage.json)

## 3. 행사 정보와 운영 입력

- **회차 선택과 등록.** 국민체육진흥공단 담당자가 사용 가능한 대관 일정 또는 공식 공연 목록에서 회차를 선택한다. 미공개 공연은 주최사가 제공한 자료로 등록할 수 있다. 장소·회차·시작·종료 예정/시간대·예상 퇴장 인원 범위·값의 근거·사용 출구를 받는다. 값이 겹치면 ‘개최 공지의 종료 예정’, ‘현장 담당자가 수정한 종료 예정’, ‘확인된 실제 종료’를 버전별로 남긴다. 판매 티켓·초대·발권·입장·퇴장은 서로 다른 수치다.
- **연결.** KOPIS와 공식 일정은 시설·회차 시간으로 후보를 제한한 후 제목·일정·출연진 근거로 연결한다. 후보가 둘이면 보류하고 정보의 출처와 수정시각을 보여준다. 127개 KOPIS 공연 중 114개가 대중음악이다. 이 편중을 클래스 가중치 또는 계층적 범주로 다루고 표본이 부족한 장르는 보류 성능도 평가한다. [KOPIS 공연 DB][kopis]
- **특성 추출.** 공단이 확보한 해당 회차의 장르와 공식 공연 소개에 명시된 값은 출처와 함께 기록한다. ‘대중음악’까지만 알거나 장르가 비면 공연명·출연진·공식 소개로 세부 분류를 제안하고, 근거가 약하면 공단 담당자가 확인할 수 있게 한다. 과거 공연과 신규 공연에 같은 기준을 쓴다. 한국어 근거 구절을 반환하는 Qwen3-8B와 Qwen3.5-9B를 동일 문서·JSON Schema로 비교한다. 체크포인트·토크나이저·추론 설정·근거 원문 해시를 고정하고, 인용 구절이 실제로 해당 공연의 분류를 뒷받침하는지 검수한다. [Qwen3-8B][qwen3] · [Qwen3.5-9B][qwen35] · [구조화 생성 구현][structured]
- **필드 사전.** 행사 유형(콘서트·팬미팅·뮤지컬·전시 등), 복수 음악 장르, 좌석/스탠딩/혼합, 실내/실외, 원문으로 확인되는 어린이 대상 여부, 복수 출연진, 회차·런타임을 별도 열로 둔다. 각 값에는 원문 구절·출처·언어·추출기 버전·검수 상태를 붙인다. 근거가 없으면 미상으로 보존한다. 기존 화면의 단일 장르 7종 대응은 정보 손실이 생기는 항목을 기록한 매핑표로 버전 관리한다.
- **공지 추출.** 통제 구간, 시작·종료, 효과, 적용 대상, 근거문장·공개시각을 제안한다. 팀 B의 간선 ID와 기간이 검증된 통지만 시나리오에 반영한다. 단순 장소명 일치는 검토 대기다. 같은 길의 공지가 겹치면 운영자가 승인한 유효 버전과 해제 기록이 우선한다.
- **운영 입력과 유사 공연.** 입력을 바꾸면 사유·담당 역할·근거시각을 남긴다. 과거 유사 공연은 예측 시점 이전의 승인 표본에서 장소·규모·요일·겹침·운영 조건을 기준으로 찾고, 일부 특성이 없으면 그 점을 표시한다. 공개 출력은 행사 가명과 승인된 통계만 쓴다. 유사 사례 수와 숫자의 출처는 기존 화면 계약과 함께 검증한다.
- **검증.** 동일 투어를 분리한 홀드아웃에서 주요 필드의 정밀도·재현율, 근거 없는 확정률, 보류율, 표본당 검토 시간, 한국어 원문과 정규화값의 대응을 잰다. 두 검수자의 불일치는 합의본과 함께 기록한다. 600개 정답을 채우는 이전 계획 대신, 라벨별 오류와 표본오차가 의사결정을 바꿀 만큼 큰 항목부터 추가 검수한다. 파인튜닝은 고정된 외부 시험에서 규칙·프롬프트 기준선을 넘는 경우에 채택한다.

## 4. 지점 교통수요 모델

**장르가 이동수요 예측에 기여하는지 검증한다.** 보유한 KOPIS 자료에서 2025년 11월 KSPO DOME에서 열린 아이돌 그룹 공연과 트로트 가수 공연은 모두 ‘대중음악’이다. 트로트와 아이돌 공연의 관객 구성이나 동행 방식이 다르면 비슷한 규모라도 종료 후 주차장 출차와 역·정류장 승차가 다르게 나타날 수 있다. 장르별 차이의 방향과 크기는 올림픽공원 관측으로 학습한다. 예매자 연령 집계가 제공되면 구매자 기준임을 기록하고, 현장에서 조사한 관람객 연령 분포와 구분한다. [올림픽공원 KOPIS 공연 자료](../../../ml/data/prepared/kopis_park_performances_2025.csv)

같은 모델·학습 기간·평가 회차에서 장르 입력만 바꿔 **장르 미사용, 공식 대분류, 대분류와 세부 장르**를 비교한다. 공연장·예상 규모·요일·예정 종료·날씨·동시 공연은 예측 시점에 확보한 동일한 값으로 맞춘다. 세부 장르 미상도 평가에 남긴다. 같은 투어가 학습에 들어가지 않은 미래 공연에서 첫 귀가 수단별 인원 비중을 6절의 독립 조사와 대조한다. 역·정류장 승차(명)와 차량문 출차(대)의 시간대별 오차와 피크 과소예측은 중간 지표로 기록한다. 차량 대수와 관객 수의 관계는 차량당 탑승인원 표본으로 검증한다.

### 배경, 공연, 과산포

같은 지점·시각·가용 데이터에서 모든 후보를 비교한다. `Y(j,I)`는 구간 안의 총승차 인원 또는 총출차 대수다. 계층적 후보는 평균 `μ`, 분산 `μ + μ²/φ`인 음이항 모형이다. 지점별 절편과 요일×시간의 주기 곡선, 추세·휴일·예보로 배경을 추정하고, 동시 공연들의 **예상 종료 전후 반응 곡선**을 더한다. 공연장과 지점별 효과는 표본이 적을수록 상위 집단 평균 쪽으로 수축시킨다. 행사 수와 공연장 좌석수만으로 규모를 확정할 수 없으므로 그 값의 출처와 미확인을 피처로 남긴다. [특별행사 대중교통 가법모델][events-paper] · [음이항 GAM 구현][nb]

```text
지점·시간 구간 평균 μ(j,I) = 구간 I에 걸친 예상 통과율 λ(j,t)의 적분
log λ(j,t) = 지점기본값 + 요일·시각 곡선 + 휴일·계절·예보 효과
              + Σ회차 공연장·지점별 반응(t − 해당 회차의 예상 종료시각, 규모, 조건)
비교 증가분 = 같은 조건의 전체 예측 − 해당 공연 변수를 제거한 배경 예측
```

짧은 시간구간에는 실제 노출시간을 사용한다. 영업시간 단축·계측 일부 중단은 별도 마스크와 노출 범위를 둔다. 출구 폐쇄로 억제된 통과량과 다른 문으로 이동한 수요를 구분한다. 예정 종료시각의 불확실성은 한 값에 고정하는 경우와, 주최사가 준 지연 시나리오를 적분하는 경우를 비교한다. 비교 증가분의 음수와 불확실성도 기록한다. 위 계산으로 반환하는 것은 비교 조건에 따른 차이다. 실제 개입의 인과효과 연구는 8절 설계를 따른다.

| 실험 | 입력·구현 | 채택 판단 |
|---|---|---|
| B0 동일 요일·시간 중앙값 | 학습기간 안에서 지점×요일×구간별 중앙값. 자료 부족 시 지점×구간, 그다음 승인된 상위 집단. 대체 단계·표본 수 제공 | 모든 모델이 같은 시간 단위와 소급 범위에서 이겨야 하는 기준 |

**이력 조건을 두 개로 고정한다.** 공개자료만 있는 조건에서는 마지막 자료 이후 기간이 길 수 있다. 기초 시계열 모델은 마지막 실제 이력과 목표시각 사이의 공백을 포함해 평가하거나 입력 부족으로 보류한다. 현장 실시간 피드가 계약된 조건에서는 피드의 지연·중단·정정까지 재현해 별도 기준선과 비교한다. 하이퍼파라미터는 시간순 내부 검증에서만 고른다. 첫 탐색은 CatBoost 깊이 4·6, 학습률 0.03·0.05와 조기종료, Chronos는 168·336시간 문맥·제로샷 후 소규모 LoRA로 제한하는 제안이다. 추론비용과 성능이 함께 개선되지 않으면 탐색을 끝낸다.

외부 연구에서 공연 일정·교통카드·배경 분리와 지점별 평가가 쓰였다. 애틀랜타 경기장 연구처럼 교통 수요 예측과 운영 최적화를 연계할 수 있으나, 현지 관객 구성·시간 해상도·열차 공급이 다른 올림픽공원은 독립 시험이 필요하다. 최신 논문·가중치의 리더보드 순위에는 이 현장 승인에 필요한 관측이 없다. [특별행사 베이지안 모형][events-paper] · [경기장 교통 수요와 열차 운영 연구][atlanta]

## 5. 관측에서 출구·목적지 수요로

### 5.1 회차 인원·종료 시각·출발 곡선

**총원.** 주최사가 퇴장 대상에 포함하는 집단·인원 범위와 근거를 수치와 함께 받는다. 전날의 예매·초대·현장 판매 예상과 당일의 유효 입장 합계를 분리하고, 재입장·직원·여러 회차에 걸쳐 머문 사람의 포함 규칙을 현장 정산표에 고정한다. 같은 사람의 중복은 현장 집계 절차에서 해소하고 연구에는 합계만 받는다. 퇴장 총원의 독립 확정이 없는 초기 공연은 주최사 범위를 운영자 조건으로 전달한다. 조건의 상·하단에 확률을 붙이려면 이후 실제 정산과 비교한 보정 자료가 필요하다.

유효 티켓 수와 실제 입장 수가 같은 분모로 쌓이면 회차별 입장률을 이항 또는 베타-이항 부분풀링으로 추정하는 후보를 시험한다. 장소·회차·요일·추정 시점별로 주최사 단일값과 비교하고, 초대·현장 판매처럼 원래 분모 밖의 입장을 별도 항목으로 정산한다. 신규 공연은 유사 공연 추정 오차와 주최사 범위의 충돌을 표시한다. 누적 유효 입장이 들어오면 이미 들어온 인원과 이후 기대 입장을 합산한다. 관측된 누적 퇴장 인원보다 작은 총원 추정은 정의·중복·시계 문제로 반환한다.

**종료의 불확실성.** 예정 종료 대비 실제 종료 잔차를 따로 모델링한다. 단일 런타임·기간 표기·앙코르·복수 회차와 당일 수정의 근거를 기록한다. 전날에는 공연장과 행사 유형의 종료 지연 분포 또는 주최사 조건을 뽑고, 종료 임박 시각에는 당시 확인된 진행 상황으로 갱신한다. 실제 종료가 확인될 때 시각 원점을 고정한다. 이로써 ‘공연이 20분 늦게 끝난 오류’와 ‘같은 종료 시각에서 관객이 빠져나오는 속도의 오류’를 각각 검증한다.

| 출발 곡선 후보 | 학습·운영 입력 | 반증과 선택 |
|---|---|---|
| 현 엔진 감마, 행사군별 경험 누적곡선 | 원래 감마의 피크·T95와 운영자 범위. 경험 곡선은 실제 종료를 맞춘 훈련 공연의 출구별 누적 비율 | 두 기준을 동일 종료 가정에서 경쟁시킨다. 종료 전 조기퇴장, 두 번째 피크, 창 끝 뒤 잔류를 따로 집계한다. |
| 남은 인원의 5분별 출발 확률 | 매 5분 아직 장내인 사람 중 나올 확률을 종료 전후 시간의 유연한 곡선, 공연장·행사군·운영 출구로 설명한다. 출구 선택은 그 시각 열린 출구 사이의 조건부 비율로 둔다. 회차별 과산포·군집 차이를 허용한다. | 미사용 공연의 5·15분 계수, 누적 곡선 오차, 피크 시각, T50/T90/T95, 조기퇴장 비중·잔류 오차를 비교한다. 같은 실측 종료를 준 시험과 실제 전날 조건 시험을 따로 낸다. |
| 종료 직전·직후 갱신 | 마지막으로 정합한 누적 출구 계수와 현장 종료 통보를 받아 남은 사람에 대해서만 미래 곡선을 다시 뽑는다. 센서 단절 때는 마지막 유효시각 이후부터 관측 오차와 모형 불확실성을 함께 전파한다. | 전향 데이터 재생에서 갱신 전후 예측과 현장 피드 없는 조건을 동시에 봉인한다. 이미 출발·도착한 사람 재주입 0명, 재실행 시 보존을 검사한다. |

각 5분 구간에서 `예상 출발 = 직전 잔류 × 조건부 출발확률`이다. 창 전 출발·장내 잔류에는 별도 칸을 둔다. 측정이 일찍 끝난 회차는 마지막까지 남은 사람 수가 확인된 범위에서 우측 검열로 취급한다. 일부 문만 잰 행사는 그 구간 관측의 우도나 오차에만 기여한다. 일부 출구의 계수를 전원 퇴장이라고 간주해 정규화하면 안 된다. 끝까지 90%를 관측하지 못한 회차의 T90은 확인 가능한 하한 또는 미확정으로 보고한다.

### 5.2 첫 목적지 배분과 관측 지점의 시차

공연에 올 때 이용한 차량·대중교통·도보 비중은 예측 시점에 알려진 범위에서 반영한다. 올 때 차에서 내려도 돌아갈 때는 지하철을 탈 수 있으므로, 두 수단을 함께 조사한 회차에서 그 차이를 추정한다. 귀가 때의 첫 보행 목적지는 주차장·승하차 지점, 역 출입구·버스 정류장, 걸어서 귀가하는 방면의 공원 출입구로 구분한다.

출구별 출발이 정해지면 `첫 수단 | 출구·시간·행사`와 `목적지 | 첫 수단·출구·시간`를 층화 설문으로 추정한다. 단순 가중 비율을 기준선으로, 표본이 쌓인 뒤에는 행사·출구 간 정보를 공유하는 다항 로짓을 후보로 둔다. 응답이 드문 셀은 상위 목적지에 합쳐 평가하고, ‘미정’과 조사 거절은 관측된 비율·무응답 보정 및 민감도 범위로 따로 남긴다. 예정된 개폐·보행시간은 기준조건에 반영한다. 운영안에서 안내 지시로 목적지가 바뀌는 효과는 엔진에서 별도 추정한다.

**관측 모형.** `H`는 공연장 출발이 관측 지점·시간에 포착되는 과정을 나타낸다. 철도는 출구별 보행시간, 역 출입구 선택, 개표까지의 대기·환승·관측 범위를 포함한다. 버스는 방향·정류장과 기다림·운행 간격을 포함한다. 자동차는 주차 위치, 보행, 탑승인원, 차량 게이트 선택 및 대기를 포함한다. 사람 수와 차량 대수의 변환은 차량을 표본단위로 측정한 **해당 공연 관객 수/차량**을 조건별로 사용한다. 일반 공원 차량과 타 공연 동승을 따로 다룬다. 동일 관객이 후속 수단에서 측정되는 경우 첫 수단은 고정하고 `H`에 관측 가능성을 둔다.

```text
기대 관측 Y(j,I) = 배경 B(j,I) + Σ[e,o,d,k] H(j,I | e,o,d,k,운영조건) × X(e,o,d,k)
제약 추정 = 관측과의 가중 오차 + 현장 계수와의 오차 + 조사 설계에 맞춘 배분 사전값과의 거리
제약 = X ≥ 0, 승인된 구조적 0, 총인원·잔류·미배정 보존, 명시한 운영자 고정 범위
```

측정 오차와 출처 상관을 반영한 가중치를 보정 표본에서 정한다. 현장 표본의 오차를 모두 0으로 고정하면 실재하지 않는 정밀도가 생긴다. 초기 구현은 희소행렬과 비음수 **볼록 이차계획**으로 고정된 관측행렬에서 해를 구한다. 식별이 약한 셀은 정규화와 사전값을 바꿔 결과 범위를 산출한다. 대기 때문에 관측행렬이 수요에 강하게 의존하는 경우, 시나리오별 엔진 전달·관측 재투영을 반복하는 후보를 별도 비교한다. 반복 상한, 보존 잔차, 변화량, 미수렴 시 마지막으로 검증된 배분을 기록한다. 예측한 교통량과 그 교통량으로 보정한 OD의 재투영 일치는 내부 정합성 검사다. 성능은 다른 행사·센서·설문에서 잰다. [OSQP 해법·불가능 판정][osqp] · [역 내 보행 OD 연구][lausanne]

**어디까지 알아낼 수 있는가.** 한 시간 안에 출구 2곳에서 50명씩 떠나고 목적지 2곳에 50명씩 도착했을 때, 대각선으로 50명씩 이동한 표와 교차해 50명씩 이동한 표의 행·열 합은 같다. 합만 알면 완전연결 `O × D` 표에 `(O−1)(D−1)` 자유도가 남는다. 동일 출발 집단에서 출구 합 `r`, 목적지 합 `c`, 전체 `N`을 정확히 알 때에만 개별 셀은 `max(0,r+c−N) ~ min(r,c)`로 제한된다. 실제 승차 자료는 시간 지연과 배경 인구가 섞여 이보다 약하다. 가능한 해의 집합에서 관심 셀과 지점 합계를 각각 최소·최대화해 식별 범위를 낸다. 실제 현장 연결표본, 관측행렬의 유효 랭크·조건수, 서로 다른 가능 해에서의 운영 순위 변화를 함께 기록한다. [OD 추가 관측의 가치][od-data]

**확률과 운영 가정.** 전향 관측으로 보정된 예측 오차의 구간과 운영자가 정한 인원·탑승인원·종료 지연의 조건 범위를 따로 표기한다. 같은 행사일의 지점별 잔차 곡선을 묶어서 뽑고, 관련된 여러 공연의 기상·종료 변화에 같은 시나리오를 적용한다. 각 표본에서 인원 보존과 폐쇄 제약을 먼저 만족한 뒤 지점별 분위수를 구한다. 목적지별 q90들을 더해 전체 q90으로 쓰면 보존도, 공동 확률도 얻을 수 없다. 운영안 A·B는 같은 표본 ID에서 차를 구하고, 통과시간·대기시간의 차이 분포로 비교한다.

**운영안의 불확실성 분해.** 행사 규모·종료 지연, 수단·출구 선택, 교통 배경, 망의 이동속도·유효 폭·안내 반응률을 시나리오에서 하나씩 고정해 순위와 지표 구간이 얼마나 바뀌는지 측정한다. 자료 없이 정한 상·하 조건에는 확률 가중치를 부여하지 않는다. 총원 조건이 결정을 지배하면 주최사 확인, 목적지 선택이 지배하면 목적지 표본, 망 통과율이 지배하면 해당 링크 실측을 먼저 배정한다. 각 추가 관측의 가치는 다음 독립 공연에서 결정 손실 또는 불확실성 폭이 줄었는지로 검증한다.

## 6. 현장 관측 설계

| 관측 항목 | 수집 방법과 단위 | 독립 검증·결측 처리 |
|---|---|---|
| 총원·종료 기준시각 | 회차별 예상 범위, 당일 누적 유효 입장, 재입장·직원 포함 여부, 실제 공연/앙코르 종료, 조기퇴장, 종료 뒤 시설 잔류 | 예매·입장·퇴장 차이를 정산한다. 여러 회차·타 행사 인원 귀속이 불명확하면 공동 집단 또는 미정으로 기록 |
| 출구별 출발 | 실제 개방된 전 출구의 **방향별** 5분 통과 집계. 설치 위치·정전·시계 오차·가림·임시 개폐 기록 | 표본 구간의 2인 수기 계수와 대조. 방향 오분류·재진입·가림은 별도 오차로 추정. 계측 중단 구간은 결측으로 유지 |
| 방문 수단과 퇴장 후 첫 목적지 | 공연×출구×출발 시간대로 층화한다. 안전한 조사 지점에서 무작위 시작 후 매 k번째 표본에 올 때 이용한 수단과 귀가 때의 첫 수단·목적지(도보 귀가 시 나가는 방면)를 각각 묻는다. 미정·응답·거절·동행 여부와 조사 시도 수를 기록한다. | 층별 선택확률과 응답률을 보정한다. 첫 목적지에서 별도로 뽑은 표본으로 의향과 실제 선택을 대조한다. |
| 지연·승용차 탑승인원 | 동의한 시간·목적지 범주 표본, 현장 구간 관찰·승차 대기·공연별 차량 표본. 수단·지점·혼잡 조건에 따라 분포로 추정 | 승객 표집의 큰 일행 과대표집 보정. 드라이브 픽업·택시·주차이용 차량과 해당 공연 일행·타 이용객을 분류 |
| 경로와 판정 결과 | 독립 지점의 방향별 통행량과 관측 가능한 대기열·지체, 안내·열차 운행·통제 변경시각 | 센서 또는 행사 단위로 보정/검증 채널 분리. 적용한 현장 개입과 관측 공백을 기록하고 운영 결정 마감 전에 경보가 도착했는지 확인 |

시계는 행사장, 출구, 차량문, 운영 단말의 기준시각과 오차를 예행 때 비교한다. 현장 보행을 방해하지 않는 위치와 중단 권한은 시설 담당자가 정한다. 연구 저장소에는 행사·시간 구간·출구·범주·계수·품질·표본 가중치만 보관하도록 설계한다. 번호판·얼굴·연락처·티켓 식별자·정확한 주거지가 필요한 조사 설계는 채택하지 않는다. 동의 및 보관·접근 범위는 자료 보유기관과 현장 절차로 확정한다. [현장 계측·관찰 지침][hse] · [계수기 검교정][fhwa-count] · [개인정보 보호법 제16조][pipa]

**조사 크기는 희망 오차에서 역산한다.** 예를 들어 하나의 모집단에서 수단 비중의 95% 오차폭 ±5%p를 원하고 보수적으로 (p=0.5)라면 단순표본 기준 (1.96²p(1-p)/0.05²=384.16)이다. 설계효과 1.5, 응답률 60%를 예시로 두면 약 961회 접촉이다. 설계값은 예행에서 얻은 거절률·일자와 일행 내 상관으로 다시 산정한다. 이는 한 모집단의 예시이고, 공연별·5분 셀별 정밀도에는 각 층의 유효 표본 수가 별도로 필요하다. 규모·날씨·동시 공연·공연장을 층화하고 표집되지 않은 조건은 승인 범위에서 보류한다. [표본 설계와 설계효과][sampling] · [특별행사 교통 계획의 관측 항목][fhwa-events]

## 7. 확증 시험과 채택 규칙

1. **후향 탐색.** 시간순으로 학습→조정→다음 행사일 평가를 이동하며, 새 투어·새 장소 제외 시험을 추가한다. 매 분할에서 통계·결측 대체·범주 사전·모수·후보 선정·구간 보정을 다시 계산한다. 겹치는 공연은 같은 날짜 블록에 둔다. 학습 목표 창과 검증 창이 겹치면 해당 행 제거, 지연 라벨은 도착일까지 유예한다.
2. **실험 사전등록.** 주 목표·비대칭 비용·비열등 마진·부차 지표·장소/시간대·시험 기간 또는 필요한 독립 사례 수·중간 관찰·중지·결측 규칙을 운영 책임자와 확정한다. 휴일·우천·동시 공연·연말 고부하와 새 투어를 필수 하위군으로 제안한다. 다수 후보는 내부 검증으로 줄인 뒤 대표 후보와 기준선을 동결한다.
3. **미래 그림자 시험.** 전날/당일 입력 스냅샷과 모델 해시, 결과를 결정 마감 전에 봉인한다. 새 공연의 정답이 도착하면 승인된 버전으로 채점한다. 과거 시험을 보고 바꾼 모델은 새 세대다. 평균 점수 외에 탈락·결측·발행 지연·예측 보류 사례를 전체 요청 분모로 보고한다.
4. **확률 검증.** 중앙값과 q10/25/75/90, interval score 또는 WIS, 80% 구간 포함률과 폭을 함께 측정한다. 좁고 과소 포함되는 구간, 전체 포함률은 좋아도 대형 공연에서 무너지는 경우를 드러낸다. 보정 표본을 시간순으로 분리한다. 분포가 바뀌면 최근 보정 자료로 재검정하며 희귀 조건의 조건부 보장을 추정하지 않는다. [WIS 원 논문][wis] · [분포 이동 시 구간 보정][conformal]

| 판정 대상 | 주 지표·집계 단위 | 통과 방식을 사전등록할 항목 |
|---|---|---|
| 교통량 수준·피크 | 지점–원구간 MAE·WAPE, 실제 최대 시간칸의 과소량, 1시간 피크 크기·발생시각, 공연일별 실패 빈도 | 정답 0이면 WAPE 분모와 유효 표본 수를 명시. 기준선과 같은 날·구간에서 비교. 기술한 채택 마진과 군집 불확실성 충족 |
| 서로 다른 운영 손실 | 과소예측 인원과 과다예측 인원을 따로 집계, 손실 `c_under × max(y−ŷ,0) + c_over × max(ŷ−y,0)` | 마진과 두 비용은 인력 배치·추가 안내·시차의 현장 비용으로 먼저 정한다. 전체 평균의 개선과 고부하 하위군의 손실 악화를 함께 판정 |
| 5분 퇴장·OD | 독립 출구별 MAE, 15분 누적과 피크, T50/T90 차이, 표본가중 첫 수단·목적지 비중의 오차와 신뢰구간 | 현장 계수기 자체 오차를 함께 보고. 관측한 집계 단위별 승인, 연결 표본이 부족하면 상위 지점 단위의 범위로 축소 |
| 보행 병목·경보 | 현장이 정한 혼잡 기준을 넘은 구간의 누락률, 경보 적중률, 혼잡 시작 시각과 최대 대기 인원 오차, 의사결정 전 선행시간 | 같은 보행망·운영안에서 고정 수단 비중과 공연별 추정 비중으로 각각 예측하고 독립 구간 관측에 대조한다. 관측한 범위와 실제 초과 사례 수, 운영시간당 오경보를 함께 기록한다. |
| 안전요원 배치안 | 동일한 출구별 출발 수요·목적지·가용 인원·통제 조건에서 요원 위치와 안내 시작 시각을 바꿨을 때의 대기시간·추가 보행 변화 | 시뮬레이션 비교와 현장 효과 검증을 구분한다. 실제로 시행한 안의 위치·시각·안내 이력을 남겨 독립 관측과 대조한다. |
| 통합 일관성 | 총원 보존, 관측 단위, 시간축, 경로 버전, 폐쇄·미배정 처리, 같은 입력 재현, 상태 표시 | 계약의 하드 오류 허용 0건. 제약 위반 예측은 운영 사용으로 승격하지 않는다. 실패 시나리오의 예상 상태까지 시험 |

**수치 예시와 실제 승인값을 구분한다.** 손실을 후보−기준으로 정의하고, 운영자가 정한 최소 편익을 `δ`라 하면 주 지표의 짝지은 95% 구간 상한이 `−δ`보다 작을 때 개선으로 판정하는 안이다. 필수 하위군에는 별도 비열등 마진을 둔다. 같은 날짜의 모든 지점·시각을 함께 뽑고, 반복 투어·연속 공연은 투어/주 블록으로 민감도 평가한다. 표본이 작으면 효과 추정과 보류 조건을 보고하고 시험을 연장한다. 예를 들어 실제 임계초과에 대한 재현율의 단측 95% 하한이 90%를 넘는 조건을 쓰면 독립 양성 29건을 모두 맞혀야 한다. 이 수치는 예시 기준이며 현장 위험 허용수준은 담당자가 정한다.

## 8. 운영 효과를 검증하는 순서

그림자 단계에서는 현장 팀이 기존 절차로 판단하고 모델의 예측·권고 시각만 봉인한다. 운영안을 적용하는 다음 단계에서는 누가 무엇을 언제 변경했고 어느 구간에 영향을 주었는지 기록한다. 안내를 바꾸면 정답 자체가 달라지므로 변경 후의 관측과 원래 예측 사이 차이를 그대로 모델 오류나 정책 효과로 환산하지 않는다.

1. **예측 성능**은 변경 전 조건에서 봉인한 값과 해당 조건의 독립 관측으로 측정한다.
2. **시뮬레이션상 운영 차이**는 동일 수요·동일 경계 조건에 안내안만 바꿔 짝지은 분포로 산출한다. 순위가 가정에 민감하면 범위와 바뀌는 원인을 제시한다.
3. **실제 운영 편익**은 안전하다고 사전 승인된 일상 업무 안에서 비교 가능한 행사군·시간대를 정하고, 가능하면 단계적 도입과 동시 대조를 사용한다. 시간대·공연 구성·인력·열차간격·날씨·사전 운영방식을 기록한다. 중요한 통제를 실험 목적으로 지연시키지 않는다. 대조가 성립하지 않는 회차에서는 기술 통계와 현장 회고만 보고한다. [행사 후 평가 지침][after-action]

새로운 운영 입력과 각종 모델 수정은 등록본에 버전과 결정 사유를 남긴다. 독립 시험 종료 전 성능을 보고 방법을 바꾼 경우 해당 자료는 개발 자료로 재분류하고 새 검정 계획을 등록한다.
