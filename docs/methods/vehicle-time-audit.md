# 차량 시각 역전 기록 제외 전후 비교

입차가 출차보다 늦은 **6,288건**을 제외하고 기존 차량 검증을 같은 조건으로 다시 계산했다. 출구 처리량 입력과 출차 증가량의 중앙값은 같았지만 개별 날짜의 시간 분포는 달라졌다. **차량 처리량 입력은 유지하고, 시간 분포는 필터 조건을 함께 기록해 해석한다.**

## 비교 조건

입력은 [2025 입출차 원본](../../geo/data/README.md)의 2,411,225건이다. 입차 시각이 출차 시각보다 큰 기록만 제외해 2,404,937건을 남겼다. 제외율은 약 0.261%이며 제외 기록의 출차 연도는 모두 2025년, 출차 날짜는 91일에 걸쳐 있다. 실제로 어느 시각 필드가 잘못 기록됐는지는 이번 자료로 판단하지 않는다.

공연일·비교일 선정, 차로 분류, 집계 시간대, 10분 창, 분위수 계산은 기존 스크립트 그대로 적용했다. CMB 등 특수 표기나 2026년 출차를 추가 제외하지 않았다. A-6 문 조합 분석과는 제외 조건이 다르다. 원본·기존 결과·화면 입력값은 보존했다.

- 처리량: 공연일 16~24시 출차 50대 이상인 86일, 출구별 1분 출차의 10분 최대 평균 분포.
- 출차 증가량: 기존 조건으로 평소와 비교 가능한 공연일 33일의 17시 이후 출차 증가량.
- 시간 분포: 평소 비교일이 충분한 공연일 28일, 출구별 16~24시 10분 증가분의 양수 부분.

필터를 적용하지 않은 시간 분포 결과는 저장소의 기존 `vehicle-check-result.json`과 전체 내용이 일치했다. 비교 기준을 재현한 뒤 같은 분석기에 정제 CSV를 넣었다. 차량 계산 엔진은 재보정하지 않았다.

## 처리량과 차량 증가량

| 지표 | 제외 전 | 제외 후 | 변화 |
|---|---|---|---|
| 북2문 처리량 상위 10% | 10.0대/분 | 10.0대/분 | 0 |
| 동2문 처리량 상위 10% | 9.8대/분 | 9.8대/분 | 0 |
| 남2문 처리량 상위 10% | 11.9대/분 | 11.9대/분 | 0 |
| 3개 출구 합계 10분 최대 평균의 중앙값 | 24.0대/분 | 24.0대/분 | 0 |
| 공연일 17시 이후 증가량 중앙값 | 910대 | 910대 | 0 |
| 관객 1,000명당 증가량 중앙값 | 122.12대 | 122.12대 | 0 |

3개 출구별 처리량 분포의 중앙값·상위 10%·최대와 표본 수는 모두 같았다. `parking.json`의 10.0·9.8·11.9대/분은 유지한다. 다만 출차 증가량의 일별 값은 33일 중 **20일**에서 달랐고, 최대 차이는 2025-10-24의 **+127대**다. 중앙값이 같다는 사실을 개별 날짜의 결과가 같다는 뜻으로 해석하지 않는다. 관객당 증가량은 기존과 같은 참고값이며 차량 이용 비율의 실측값이 아니다.

## 출차 시간 분포

아래 값은 28일의 출구별 통계 중앙값이다. 50% 시점은 **16시부터의 분 인덱스**이며 공연 종료 후 경과 시간이 아니다. 증가분에는 다른 시설 이용자·비교일 차이가 섞여 있다.

| 출구 | 10~90% 시간 폭 전→후 | 50% 시점 전→후 | 가장 붐빈 60분 비율 전→후 |
|---|---|---|---|
| 북2문 | 332.5→333.0분 (+0.5) | 276.5→274.5분 (−2.0) | 47.66→44.44% (−3.23%p) |
| 동2문 | 367.0→369.0분 (+2.0) | 257.0→258.5분 (+1.5) | 36.26→34.68% (−1.58%p) |
| 남2문 | 346.5→346.5분 (0) | 262.0→276.0분 (+14.0) | 45.50→45.50% (0%p) |

가장 붐빈 60분은 연속된 이동 창의 최댓값이다. 지하철 검증에서 사용한 고정 시 단위의 가장 붐빈 1시간과 구분한다. 전후 차이는 각각의 중앙값을 뺀 값이며 일별 변화량의 중앙값은 아니다.

비교 가능한 날짜·출구 조합 84개는 그대로였지만 **38개 조합**의 일별 통계가 변했다. 10분 구간 4,032개 중 출차·평소·증가분이 바뀐 구간은 **629개**다. 개별 날짜·출구의 10~90% 시간 폭 차이는 최대 **+115분**(2025-08-15, 북2문), 50% 시점 차이는 최대 **+90분**(2025-08-03, 남2문)이었다. 작은 전체 제외율만으로 일별 시간 분포에 영향이 없다고 볼 수 없다.

역전 기록은 공연일 16~24시 출차 중 511건, 전체 날짜의 17시 이후 출차 중 1,702건이었다. 공연일 기록과 평소 비교일 기록을 모두 같은 기준으로 제외했으므로 보정 후 증가분이 반드시 줄어드는 것은 아니다. 비교일 보정과 양수 절단 때문에 시간 분포의 대표 시점도 달라질 수 있다.

실제 공연 종료 시각은 여전히 없어, 정제 후에도 공연 종료 후 50%·90% 출차 시간을 실측으로 검증하거나 퇴장 시간을 확정할 수 없다. 주차장까지 걷는 시간과 차량당 인원 가정은 이번 점검으로 바꾸지 않았다.

## 재현과 결과 파일

```sh
PYTHONDONTWRITEBYTECODE=1 python3 geo/validate/vehicle_time_audit.py
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s geo/validate -p 'test_*.py'
```

결과 폴더는 [geo/validate/vehicle-time-audit](../../geo/validate/vehicle-time-audit/)다.

| 파일 | 내용 |
|---|---|
| `comparison.json` | 제외 건수·출차 날짜·차로별 분포, 전후 집계, 변화량, 기준 결과 재현 여부 |
| `before-parking.txt`, `after-parking.txt` | 기존 처리량·차량 증가량 분석의 전후 출력 |
| `daily-deltas.csv` | 통계가 달라진 날짜·출구의 전후 값과 차이 |
| `curve-deltas.csv.gz` | 값이 달라진 10분 구간의 출차·평소·증가분 전후 비교 |

정제 CSV는 임시 폴더에서 만들고 계산 후 자동 정리한다. 원본과 기존 결과를 덮어쓰지 않으므로 이후 보고에서는 이 사후 점검과 기존 결과의 필터 조건을 구분한다. 이 점검은 출구 처리량 입력을 뒷받침하지만 시각 필드의 정확성이나 실제 퇴장 곡선을 인증하는 검증은 아니다.
