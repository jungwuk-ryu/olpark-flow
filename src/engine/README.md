# 계산 엔진 (`src/engine`)

UI와 분리된 순수 TypeScript. 입력 파일 모양은 `docs/data-contract.md`를 따른다.

| 파일 | 하는 일 |
|---|---|
| `egress.ts` | 퇴장 곡선. 총 퇴장 시간(95%가 나오는 시각)·정점 시각 → 감마 분포 모수 → 분 단위 비율 (합 = 1) |
| `simulate.ts` | 1분 단위 보행 흐름: 출구 → 방면 분배(안내 × 반응률) → 걷는 지연 → 병목 대기 → 줄 번짐 → 교차점 |
| `vehicle.ts` | 차량 출구 대기 (출구별 줄 하나) |
| `optimize.ts` | 분산안 격자 탐색 (안내 비율 × 시작 시각 × 차량 출구 배정) |
| `status.ts` | 상태 색: 여유 / 보통 / 병목 / 위험 |
| `endtime.ts` | 종료 시각의 범위를 시계 시각으로 옮긴다: 그 시각에 대기가 닿는 폭, 정점·해소 시각의 범위 |
| `walk.ts` | 공원 전체 보행로(`walkways.json`) 위의 1분 단위 보행 흐름. 화면의 지도가 쓰는 엔진이다. 운영자가 놓은 막기·장애물(폭 줄이기)·안전요원을 반영한다 |

## 핵심 규칙

- 시간: 배열 t번째 = 종료 후 t~t+1분. 대기 인원은 그 1분이 끝난 시점 값. `maxQueueMinute`, `clearMinute`는 "종료 후 몇 분"으로 보고한다.
- 병목 용량 = 유효 폭 × 폭 1m당 분당 통과 인원(통로 82 · 문 115 · 계단은 통로의 60%) × 날씨 보정. 숫자는 `assumptions.json`.
- 대기(t) = 대기(t−1) + 도착(t) − 통과(t), 통과(t) = min(대기 + 도착, 용량). 같은 길을 쓰는 무리끼리는 (대기 + 도착) 비율로 나눈다.
- 줄 번짐: 다음 길의 대기가 `queueAreaM2 ÷ 0.46㎡`를 넘지 않게 이번 길 통과량을 줄인다. 걷는 중인 사람은 한계에 넣지 않는 근사.
- 교차점: 직전 1분에 차량이 있었으면 보행 용량 × 60%, 보행자가 있었으면 차량 처리량 × 40%.
- 역 방면 길을 걷는 사람은 지하철을 타러 가는 관객뿐이다(`stationShare`). 차로 가는 관객(차량 비율)은 주차장까지 걷는 시간(`walkToLotMinutes`)만큼 늦게 출차해 차량 출구에 줄을 선다. 버스·도보 귀가·픽업 관객은 길 계산에 넣지 않는다. 세 무리의 인원은 `totals.modePeople`에 남고 합은 관객 수다. `stationShare`가 없으면 차량을 뺀 전원이 역으로 간다.
- 1인당 추가 시간은 계산에 넣은 사람(역으로 걷는 사람 + 차량 탑승자) 수로 나눈다.
- 종료 시각은 전날에 확정되지 않는다. 계산은 종료 후 분으로 하고, 공연이 d분 늦게 끝나면 같은 흐름이 d분 늦게 나타난다고 본다. 그래서 줄의 크기는 종료 시각과 무관하고 시계 시각만 범위가 된다. `clockEnvelope`는 종료가 범위 안에서 움직일 때 각 시각에 대기가 닿는 최소·최대를, `clockTimes`는 종료 후 몇 분의 시계 시각과 그 범위를 낸다.
- 우회 추가 보행 = 각자 간 방면의 보행 시간 − 그 출구에서 가장 가까운 방면의 보행 시간. 현재 운영안에서도 0이 아닐 수 있다.
- **안내요원은 길 용량을 늘리지 않는다.** 동시에 운영할 분기점 수(안내요원 ÷ `staffPerJunction`)만 제한하고, 효과는 안내 반응률로만 들어간다.
- 분기점이 여러 곳이면 한 곳씩 차례로 정하는 탐욕적 탐색이다.

## 보행로 전체 계산 (`walk.ts`)

- 무리 = 출구 한 곳에서 목적지 한 곳으로 가는 사람들. 길 종류별 비용을 곱한 거리가 가장 짧은 길로 간다.
- 그 길보다 5% 안쪽으로 더 먼 길이 있으면 셋까지 나눠 간다 (`ALTERNATIVES`, 가정). 몫은 서로 다른 구간의 가장 좁은 폭에 비례하고 더 먼 길일수록 줄어든다. 나란한 두 길 가운데 몇 m 짧은 쪽에 모두 몰리지 않게 하려는 것이다.
- 토막 용량 = 유효 폭 × 폭 1m당 분당 통과 인원. 마주 오는 흐름은 용량을 나눠 쓰고 자리는 방향별로 센다.
- 다음 토막에 못 들어간 사람은 지금 토막 위에 서서 기다린다. 토막 위 사람(서서 기다리는 사람 + 걷는 사람)이 폭 × 길이 ÷ 정체 시 1인당 면적에 닿으면 그 토막으로도 못 들어가 줄이 뒤로 번진다.
- 걷는 시간은 1분 단위로 반올림해 늦춘다. 토막 위의 걷는 사람은 실제 길이로 센다(1분에 들어온 사람 × 걷는 분). 반올림 때문에 짧은 토막에 1분치 사람이 몰려 보이지 않게 한다.
- 역은 받는 한도(sink)가 있다. 올림픽공원역은 개찰구 관측값, 다른 역은 계단 폭 3m 가정.
- 상태: 들어오려는 사람이 용량의 70% 이상이면 보통, 100% 이상이면 병목, 토막 위 1인당 면적이 정체 기준의 1.2배 이하면 위험. 10m보다 짧은 토막은 10m로 보고 판정한다 (`DANGER_STRETCH_M`).
- 막은 길은 아무도 지나지 못하고 길을 다시 찾는다. 장애물은 남은 폭만큼만 지난다. 안전요원을 세운 길에서는 안내를 따르는 사람(반응률, 가정)만 그 길을 피하거나 안내받은 역으로 간다. 안전요원은 용량을 늘리지 않는다.
